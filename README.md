# Savanna Wiki

A FastAPI article and comments API with a Vue frontend and a living Three.js
savanna in the background.

The scene includes zebras, impalas, elephants, giraffes, a lion and Nile
crocodiles. Animals drink, graze, browse acacia leaves and avoid each other.
The lion stalks from cover and pounces; crocodiles ambush drinking animals
and pull their prey underwater. Generated percussion, animal calls and
splash effects are available through the sound controls.

## Run locally

Requirements: Python 3.14+ and [uv](https://docs.astral.sh/uv/).
No Node.js installation or frontend build is needed.

Start the API from the repository root:

```sh
cd backend
uv sync --locked
uv run fastapi dev
```

In a second terminal, from the repository root:

```sh
python3 -m http.server 5173 --bind 127.0.0.1 --directory wiki/simplefront
```

Open <http://127.0.0.1:5173/>. The API is at <http://127.0.0.1:8000> and its
documentation is at <http://127.0.0.1:8000/docs>.

Click **Sound off** to enable audio. The settings button controls percussion,
volume, wildlife sounds and optional rain audio. The animated background
pauses in hidden tabs and follows the system's reduced-motion preference.

## Layout

- `backend/`: Python application, locked dependencies and coding guidelines.
- `wiki/simplefront/`: frontend, locally vendored Vue/Three.js, 3D models and audio.
- `wiki/articles/`: Markdown articles; the first line stores the author.
- `wiki/comments.json`: the animal comments shown by the application.

The servers remain separate. The API resolves article data relative to its
source files, so this directory layout must be retained.
